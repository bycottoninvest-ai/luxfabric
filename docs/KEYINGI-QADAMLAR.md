## Keyingi (tartib bilan)
1. **Domen HTTPS** — brauzerda `https://luxfabricshop.uz` ochilsin
2. **Saytni deploy** — lokal emas, shu domenga chiqsin
3. **Meta token** — developers.facebook.com → Page Access Token
4. Admin → Instagram → **Meta/DM** → token + domen → **Ulanishni tekshirish** → **Instagramni yoqish**
5. Reel/Story → **Instagramga joylash**
